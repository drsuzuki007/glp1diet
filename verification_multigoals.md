# Multiple Learning Goals Verification

Authenticated browser verification confirmed that an existing `食事・生活習慣を整える` goal remains selected when `GLP-1の基礎を知る` is added. The dashboard presents both labels in the current-goals badge, and each selected card remains active rather than replacing the prior selection.

The final recommendation panel retained the learner's highest-priority in-progress lesson, then showed one GLP-1 course and one lifestyle course. Both goal-aligned cards show a category-specific reason, demonstrating that the recommendation capacity is distributed across all selected goals rather than being filled by a single theme.

The GLP-1 goal was then individually removed. The dashboard retained only the lifestyle goal and replaced the GLP-1 recommendation with a second lifestyle recommendation, confirming that removal persists and the remaining goal alone determines the thematic recommendation priority.
